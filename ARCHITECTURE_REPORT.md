# Welmi — архитектура

Дата: 15.11.2026. Flutter 3.44.4, Dart 3.12.2. 261 Dart-файл в `lib/` (~42 тыс. строк без
сгенерированной локализации), 19 фич.

## 1. Слои

```
lib/main.dart
  └─ app/            запуск (bootstrap), корневой виджет (WelmiApp), блокировка, push-маршруты
       │
       ├─ features/<feature>/{data,domain,presentation}     19 фич
       │        │
       └────────┴─ core/
                    ├─ config/         переменные окружения (String.fromEnvironment)
                    ├─ services/       Supabase, AI, уведомления, трекер дня, здоровье, голос
                    ├─ models/         профиль, записи дневника, планы
                    ├─ theme/          палитра, токены, типографика, язык, режим темы
                    ├─ widgets/        дизайн-система: AppButton, AppCard, AppAppBar, AppSnackbar…
                    └─ utils/, network/
supabase/functions/   Edge Functions (Deno): feedback, push, reminders, подписка
```

Зависимости направлены вниз: `features → core`, `app → features + core`. `core` фичи не
импортирует (кроме `SubscriptionService`, который лежит в `features/profile/domain` и
используется из `app/bootstrap.dart`).

## 2. Как модули общаются

| Модуль | Роль | Кто использует |
|--------|------|----------------|
| `SupabaseService` (+ миксины `ProfileQueries`, `DiaryQueries`, `TrackingQueries`) | Единственная точка запросов к основным таблицам | `UserDataService`, `DailyTracker`, экраны дневника/воды/веса |
| `UserDataService` (ChangeNotifier) | Профиль, вес, замеры текущего пользователя | почти все экраны; `DailyTracker` слушает его |
| `DailyTracker` (ChangeNotifier) | Итоги дня: калории, макросы, вода, шаги; офлайн-очередь | главная, дневник, вода, активность, уведомления |
| `AiService` → `ai/` (клиент, распознавание еды, чат, планы, транскрибация) | Вся работа с OpenRouter/Gemini | сканер, чат, голосовой ввод, онбординг, тренировки |
| `NotificationService` → `notifications/` | Локальные напоминания | bootstrap, WelmiApp, настройки уведомлений |
| `PushNotificationService` | FCM-токен и маршруты по нажатию | WelmiApp |
| `HealthSyncService` | Health Connect / HealthKit (чтение) | WelmiApp, главная, активность |
| `SubscriptionService` + `SubscriptionRepository` | Покупки и серверный entitlement | профиль, экран подписки |
| `UnitsService`, `localeProvider`, `ThemeModeController` | Единицы, язык, тема | всё приложение |

Поток данных типичного действия («добавить воду»): экран → `DailyTracker.addWater` →
оптимистичное обновление и `notifyListeners` → `SupabaseService.addWaterEntry` → при ошибке
запись уходит в офлайн-очередь (`TrackerStorage`) и отправляется позже → `NotificationService`
перестраивает напоминания о воде.

## 3. Оценка

**Управление состоянием.** Синглтоны-сервисы + `ChangeNotifier` + `setState` на экранах.
Пакета для DI или состояния нет. Для приложения такого размера это работает и понятно; цена —
сервисы трудно подменять в тестах (тесты покрывают чистую логику и виджеты, но не сервисы с
сетью). Переход на Riverpod/Bloc **не рекомендую**: измеримой выгоды нет, а переписать пришлось бы
каждый экран.

**Слой данных.** Запросы к основным таблицам собраны в `SupabaseService`. Отдельные
репозитории есть у рецептов, истории, подписки. Из сервисов вне слоя данных к таблицам
напрямую обращается только `PushNotificationService` (`device_tokens`).

**Навигация.** Императивная: `Navigator.push(smoothPageRoute(...))`, четыре вкладки в
`MainShell` + сканер. Именованных маршрутов и deep links нет (кроме OAuth-редиректа и
маршрутов push/виджета). Для текущих сценариев достаточно.

**Конфигурация.** Один файл, только compile-time окружение. Хорошо.

**Локализация.** ru/en/ky, ~900 ключей, генерация `flutter gen-l10n`. Интерфейс локализован
полностью; контент (библиотека упражнений, резервные планы тренировок и питания, каталог
рецептов, AI-промпты) — только на русском.

## 4. Что изменено в этой сессии

- **`MainShell`:** вкладки создаются при первом открытии, а не все четыре на старте; разделы
  остаются в дереве под сканером и не перезагружаются после него; системная «Назад» ведёт на главную.
- **Главная** подписана на `DailyTracker` и `UserDataService` — раньше после добавления воды
  или еды на другом экране цифры оставались старыми до ручного обновления.
- **Язык** загружается до первого кадра (`localeProvider.ready`), смена языка перестраивает
  расписание и названия каналов уведомлений.
- **Справочник напоминаний** берёт тексты из локализации; из `NotificationSettings` убран
  дублирующий русскоязычный метод.
- Общие виджеты `Pressable` и `AnimatedCount` в `core/widgets`.
