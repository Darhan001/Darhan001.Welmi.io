# Welmi — аудит проекта

Дата: 15.11.2026. Ветка `refactor/welmi-transformation`.

**Глубина проверки.** Полный проход по репозиторию выполнила сессия 10.11 (она прочитала слой
сервисов, Edge Functions, конфигурацию платформ; её выводы восстановлены из журнала). В сессии
15.11 заново и целиком прочитаны: запуск (`app/`), уведомления, главная, вода, навигация,
AI-клиент, `UserDataService`, тема, манифесты, Gradle, Edge Functions. Остальные экраны
проверены выборочно — поиском по шаблонам (жёстко заданные строки и цвета, `GestureDetector`,
состояния загрузки, журналирование), а не построчным чтением.

## 1. Стек

| | |
|---|---|
| Клиент | Flutter 3.44.4 / Dart 3.12.2, `google_fonts` (Inter), собственная дизайн-система в `core/theme` и `core/widgets` |
| Бэкенд | Supabase: Postgres + RLS, Auth (в т.ч. Google OAuth), Storage (`avatars`), 5 Edge Functions |
| AI | OpenRouter (Gemini 2.5 Flash и резервные модели) → прямой Gemini REST как запасной путь |
| Локальное хранение | SharedPreferences: настройки, кэш дня, офлайн-очередь |
| Платформы | Android (minSdk 26), iOS; каталоги `web/`, `linux/`, `macos/` есть, но не поддерживаются |
| Языки | ru, en, ky |

## 3. Зависимости

Все 29 прямых зависимостей импортируются в коде — неиспользуемых нет.

| Пакет | Замечание |
|-------|-----------|
| `device_preview` | Инструмент отладки в `dependencies`. Импортируется из `lib/`, поэтому в `dev_dependencies` перенести нельзя; **теперь подключается только в debug**. |
| `firebase_core`, `firebase_messaging` | В сборке есть, но на Android плагин `google-services` отключён — FCM не инициализируется. Либо подключить, либо убрать. |
| `google_generative_ai` | Используется для плана питания; пакет объявлен автором устаревшим. |
| `flutter_local_notifications` 18, `local_auth` 2, `fl_chart` 0.68, `sentry_flutter` 9, `flutter_lints` 3 | Отстают на мажорные версии. Не обновлялись намеренно. |
| `in_app_purchase_android`, `local_auth_android`, `local_auth_darwin` | Платформенные реализации указаны явно — нужны для их специфичных API. |

## 6. Что не проверялось

- Работа на устройстве или эмуляторе: в среде нет подключённых устройств. Вёрстка проверена
  только виджет-тестами (в том числе на экране 320×568 с увеличенным шрифтом — для главной).
- Сборка iOS: нужна macOS.
- Рабочая база Supabase, развёрнутые версии Edge Functions, секреты.
- Реальные покупки, Health Connect / HealthKit, доставка push.
- Производительность (частота кадров, время запуска, память) — замеров не было; изменения
  по производительности сделаны по анализу кода (меньше запросов и построений), а не по профилю.
